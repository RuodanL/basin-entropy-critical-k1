# Basin Entropy in Critical K=1 Boolean Networks

Python code accompanying the paper:

**Permutation order governs basin entropy in critical one-input Boolean networks**

Ruodan Liu, Ahana Ghosh, Sean Campbell, Venkata Sai Narayana Bavisetty, Matthew Wheeler, and Claus Kadelka (2026).

## Overview

This repository contains the Python code used to generate the numerical results in the paper.

The study investigates basin entropy in critical one-input Boolean networks and establishes its relationship with permutation order. The simulations illustrate the nonadditivity of basin entropy and sharp bounds on the logarithmic period deficit.

## Reproducing the figures

The script `reproduce_figures.py` generates the numerical results underlying:

- **Figure 2:** Mean and worst-case effects of nonadditivity.
- **Figure 3:** Uniform bounds on the logarithmic period deficit and the relationship between basin entropy and permutation order.

Figure 1 is a schematic illustration and is not generated by this script.

## Requirements

- Python 3.10 or later
- NumPy
- Matplotlib

## Usage

Run the simulation and generate the figures:

```bash
python reproduce_figures.py
```

The script uses a fixed random seed for reproducibility and saves the generated figures to the working directory.

## Simulation parameters

The default simulations use:

- 45 distinct values of the number of relevant nodes, between 1 and 10⁴, with 3,000 samples per value.
- 1,000 signed permutations at a fixed number of relevant nodes, m = 128.
- Random seed: 1989.
